# Agentic AI Systems — Lab Assignments Solutions

This repository contains complete, tested, and verified solutions for **all 14 Labs (28 Graded Assignments)** from the *Agentic AI Systems Lab Guide* (School of Computer Science & Engineering, KLE Technological University).

Each lab is organized into its own directory with the reference program, and subfolders for **Assignment 1** and **Assignment 2**, each containing:
- `solution.py`: Complete, standalone, well-documented Python implementation extending the reference architecture.
- `output.txt`: Captured console execution output and transcripts verifying that all rubric checks pass.
- `README.md`: Detailed documentation of the problem statement, key implementation details, and verification steps.

## How to Run Any Assignment

Navigate to any lab assignment folder and execute the solution:

```bash
cd "Lab 1/Assignment 1"
python solution.py
```

All programs run offline, deterministically, and require zero external API keys or third-party dependencies.
